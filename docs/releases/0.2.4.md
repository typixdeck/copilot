# Copilot 0.2.4 预发布版

针对 ESP32-S3 备份读取中断及维护模式等待问题，更新官方 RAM stub v1.2.2，保留 CDC 连接直到观察到 ROM，并拒绝直接复用版本未知的残留 RAM stub。继续保留板级检查、Polkit 授权、完整私有备份和独立读回校验。

- 新增 DIY 0.4.1 固件目录，在线签名和随包离线目录同步更新；统一“写入”，缺少缓存时自动下载。
- 保留详细阶段日志、失败位置与本地固件缓存管理。
- `typix-copilot_0.2.4-1_arm64.deb` 是完整安装包，适用于官方 Raspberry Pi OS Trixie ARM64。系统 Python/GTK/Polkit 等依赖由 deb 声明。
- 软件回归测试通过（177 项），七个分发镜像与 Ed25519 签名校验通过。

**预发布：完整 CM4 备份/写入/独立回读仍待验收，不能宣称通信问题已完全修复。DIY 0.4.1 也尚未完成真机验收，电量 0% 问题仍在定位。** 本次发布没有刷写硬件。完整固件会清除 ESP 的 Wi-Fi、配对和偏好设置。
