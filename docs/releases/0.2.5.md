# Copilot 0.2.5 · 下载与代理修正

此前 DNS、TLS、超时和缓存读写错误被统一显示成“固件下载或文件校验失败”，容易误判固件损坏。现在界面和详细日志保留固定错误类别，并显示有界 HTTP 状态码。

- 固件目录和镜像下载遵循桌面的 HTTP/HTTPS 代理及 NO_PROXY，支持已配置的 FlClash 本地代理。
- TLS 证书、签名、文件大小、SHA-256、镜像结构和禁止重定向的检查全部保留；不输出代理凭据或异常原文。
- 182 项本地测试通过。CM4 从 0.2.3-1 升级后，实际从 GitHub 下载完整 DIY 0.4.1，并通过校验和离线缓存复用。
- 安装包适用于官方 Raspberry Pi OS Trixie ARM64；Store 已同步同一完整 deb。

本次没有刷写 ESP32。完整备份/写入/回读流程仍待整机验收，因此继续标为预发布版；DIY 0.4.1 的硬件验收状态与电量问题未改变。真机下载故障还涉及 FlClash TUN DNS 失效，重启其客户端后恢复；本版不会改动代理订阅或节点配置。
